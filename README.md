# 🎓 BSEBTimes™ — Bihar School Examination Board Digital Platform
> **बिहार विद्यालय परीक्षा समिति (मैट्रिक 10वीं एवं इंटर 12वीं) आधुनिक डिजिटल तैयारी एवं मूल्यांकन मंच**

BSEBTimes™ बिहार बोर्ड के लाखों विद्यार्थियों के लिए डिज़ाइन किया गया एक अत्याधुनिक, तीव्रगामी और पूर्ण-सुविधायुक्त वेब प्लेटफॉर्म है। इसमें 10वीं (मैट्रिक) और 12वीं (इंटर — I.Sc, I.A, I.Com) के सभी विषयों का विस्तृत पाठ्यक्रम, बहुविकल्पीय प्रश्न (MCQ), 10 वर्षों के PYQ, विषयनिष्ठ प्रश्नोत्तर (Subjective Q&A), और वास्तविक BSEB OMR शीट सिम्युलेटर सम्मिलित है।

---

## 🚀 मुख्य विशेषताएँ (Key Features)

### 1. 📖 कक्षा 10वीं मैट्रिक संपूर्ण 103 अध्याय कवरेज (100% Complete)
- **गणित (Mathematics)**: 15 अध्याय (वास्तविक संख्याएं से प्रायिकता तक)
- **विज्ञान (Science)**: 16 अध्याय (भौतिकी, रसायन, जीवविज्ञान)
- **सामाजिक विज्ञान (Social Science)**: 18 अध्याय (इतिहास, भूगोल, राजनीति विज्ञान, अर्थशास्त्र, आपदा प्रबंधन)
- **हिंदी (Hindi)**: 24 अध्याय (गोधूलि गद्य + पद्य एवं वर्णिका)
- **संस्कृत (Sanskrit)**: 14 अध्याय (पीयूषम भाग 2 संपूर्ण)
- **अंग्रेजी (English)**: 16 अध्याय (Panorama Part 2 Prose & Poetry)

### 2. 📝 विषयनिष्ठ प्रश्नोत्तर अध्ययन प्रणाली (Subjective Q&A Reading System)
- **2 अंक लघु-उत्तरीय प्रश्न** (Short Answers) एवं **5 अंक दीर्घ-उत्तरीय प्रश्न** (Long Answers)
- बिहार बोर्ड की आधिकारिक **स्टेप-मार्किंग योजना** (Step-wise Marking)
- **टॉपर प्रस्तुति बिंदु** (Topper Tips) और गणितीय/वैज्ञानिक निगमन
- प्रश्न फिल्टर (All, 2M, 5M, BSEB PYQ, NCERT अभ्यास), कीवर्ड सर्च और वन-क्लिक कॉपी

### 3. ⭕ वास्तविक BSEB OMR शीट सिम्युलेटर (`/omr-simulator`)
- 50/100 प्रश्न OMR टेस्ट विद लाइव काउंटडाउन टाइमर (45:00 / 60:00)
- 100 अंक विषयों के लिए 50 बबल्स एवं 70 अंक प्रायोगिक विषयों के लिए 35 बबल्स का नियम
- तात्कालिक मूल्यांकन (Instant Score, Percentage, 1st/2nd/3rd Division, एवं जिला रैंक परसेंटाइल)

### 4. 📄 2026 आधिकारिक मॉडल पेपर सूट (`/model-papers`)
- 10वीं मैट्रिक, 12वीं विज्ञान (I.Sc), 12वीं कला (I.A), 12वीं वाणिज्य (I.Com), एवं 200 अंक भाषा पत्र
- मॉडल पेपर्स का OMR टेस्ट एवं मॉडल हल पूर्वावलोकन

### 5. 🗺️ बिहार के सभी 38 जिलों की रैंकिंग (`/ranks`)
- पटना, गया, मुजफ्फरपुर, भागलपुर, दरभंगा, रोहतास, पूर्णिया समेत सभी 38 जिलों एवं 534 प्रखंडों का लाइव लीडरबोर्ड

### 6. 🎓 टॉपर कॉपी प्रस्तुति एवं अध्ययन टाइम टेबल (`/toppers`)
- टॉपर उत्तर-पुस्तिका के 4 स्वर्ण नियम, दैनिक अध्ययन दिनचर्या एवं 1:1 मेंटरशिप

## 💻 स्थानीय विकास (Local Development)

### आवश्यकताएं (Prerequisites)
- [Node.js](https://nodejs.org/) (v18.17 या उच्चतर)
- npm, yarn, या pnpm

### स्थापना (Installation)

```bash
# 1. रिपॉजिटरी क्लोन करें (या प्रोजेक्ट डायरेक्टरी में जाएं)
cd bsebtimes-platform

# 2. डिपेंडेंसी इंस्टॉल करें
npm install

# 3. डेवलपमेंट सर्वर शुरू करें
npm run dev
```

ब्राउज़र में **[http://localhost:3000](http://localhost:3000)** खोलें।

### प्रोडक्शन बिल्ड (Production Build)

```bash
# प्रोडक्शन बिल्ड तैयार करें
npm run build

# प्रोडक्शन सर्वर चलाएं
npm run start
```
